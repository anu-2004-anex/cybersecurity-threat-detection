
# 🚨 Cybersecurity Threat Detection Dashboard

> A futuristic, real-time **Cybersecurity Threat Monitoring System** built using **Streamlit**, with integrated **AI voice alerts**, an animated **3D threat map**, and live attack simulations.

---

## 🧠 Project Highlights

🔹 Real-time threat detection and visualization  
🔹 AI-based voice alerts for critical threats  
🔹 3D interactive map using PyDeck  
🔹 Live threat log with dynamic updates  
🔹 Threat severity level indicators  
🔹 Secure admin login using SHA-256 hashing  
🔹 Neon dark theme for modern cyberpunk aesthetics

---

## 🎥 Live Preview


## 🛠️ Tech Stack

- **Frontend:** Streamlit (Neon-themed UI)
- **Backend:** Python
- **Libraries:**  
  - `pandas`, `plotly`, `pydeck` – for data visualization  
  - `pyttsx3` – for AI voice alerts  
  - `hashlib` – for secure password hashing  
  - `threading` – for async voice alerts  
  - `base64`, `time`, `random` – for simulation and interaction

---

## 🔐 Features

| Feature                     | Description                                                        |
|----------------------------|--------------------------------------------------------------------|
| **Admin Login**            | Only admins can log in and access sensitive controls               |
| **Voice Alerts**           | AI voice alerts for threat severity (Low to Critical)              |
| **3D Threat Map**          | Animated map showing threat origins using colored scatterplots     |
| **Threat Score Analysis**  | Gauge meter and scatter plot to visualize intensity                |
| **Live Logs**              | Real-time updates of incoming threat data with analysis            |
| **Search Functionality**   | Filter threat data based on state or country                       |
